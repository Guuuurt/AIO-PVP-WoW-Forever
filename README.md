## About the addon

AIO PVP brings customizable PvP nameplates, aura and crowd-control tracking, player/target portrait options, resource timers, battle text, macro templates, fonts, and themes into one settings window.

- Target: official WoW Forever, PvP ruleset, client 1.60.1 / Interface 16001.
- Open settings with `/aiopvp` or `/gpp`.
- AIO's core features do not require a separate addon.
- The MSBT provider requires the separately installed Forever-compatible [MikScrollingBattleText (New API)](https://www.curseforge.com/wow/addons/mikscrollingbattletext).
- The 0.1.163 bundle includes Musca Auras, the Forever adaptation of WeakAuras, in five separate addon folders. Install all included folders and fully restart WoW. Do not mix it with another WeakAuras build using the same folder names.
- Disable Plater when using AIO nameplates. Disable BetterBlizzFrames and reload before using AIO portrait customization.
- Optional custom fonts require your own font files.

## Helpful bug reports

Include the AIO version, client version/build (`/dump GetBuildInfo()`), steps to reproduce, expected and actual behavior, relevant settings, and other addons affecting the same UI. Mention whether it happens in combat, against players or NPCs, or during world PvP. Include a Lua error or screenshot when available.

**Issues and attachments are public.** Remove account details, personal information, chat, and other sensitive content. Do not upload entire WTF folders or unreviewed SavedVariables files.

## Beta status

Development and in-game testing are ongoing. Mocked/static checks are not a guarantee of live combat behavior. WoW Forever restricts some combat information; requests cannot override those restrictions. Imported auras may require Forever-specific changes. Feature requests are welcome but are not promises of implementation.

Please keep reports constructive and respectful. Thank you for helping improve AIO PVP!
